How to use:
1. Create a folder and save all files into it.
2. (Optional) Add a real photo 'avatar.jpg' or replace the placeholder image link in index.html.
3. To test locally, open index.html in a browser.
4. To deploy on GitHub Pages: push these files to a public repo and enable Pages from root branch. URL will be https://your-username.github.io/repo-name/
5. To deploy on Netlify: drag & drop the folder to Netlify's Deploy panel or connect a GitHub repo and set publish directory to '/'.

Notes:
- Contact form is demo only (no backend). To receive messages you can connect Netlify Forms or a small server.
