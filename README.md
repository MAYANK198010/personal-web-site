# Mayank — Personal Portfolio

Modern responsive personal portfolio for Mayank, a Diploma in Computer Engineering student.

## Included
- Responsive single-page portfolio homepage
- Project showcase
- Skills and learning journey
- Contact section
- Printable/downloadable resume page at `resume.html`
- Accessible mobile navigation
- SEO metadata and reduced-motion support

## Deploy
This is a static site and can be served directly from GitHub Pages.
